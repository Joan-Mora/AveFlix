# Instrucciones para Audio Inteligente (AI) Premium

Para que el juego AveFlix detecte automáticamente tus audios generados por Inteligencia Artificial (Audios Cinematográficos, Tensión, Reloj, etc.), simplemente debes reemplazar los archivos en esta carpeta asegurándote de usar **exactamente** estos nombres (en minúsculas y formato `.mp3`):

## Efectos de Sonido (SFX)
- `sfx_tick.mp3`: El sonido de un reloj o latido contrarreloj (se reproduce 1 vez por segundo cuando quedan 5 segundos).
- `sfx_timeup.mp3`: Sonido dramático de tiempo agotado (gong, caída de graves, impacto cinemático).
- `sfx_swoosh.mp3`: Transición rápida cuando entra la siguiente pregunta.
- `sfx_success.mp3`: Sonido de victoria cuando aparece el Top 3 final.
- `sfx_error.mp3`: Sonido de error (feedback local del jugador).
- `sfx_click.mp3`: Interacción básica de botones.

## Música de Fondo (BGM)
- `bgm_menu.mp3`: Tema principal corporativo / aventura suave para el Lobby y menú.
- `bgm_tension.mp3`: Tema intenso, rítmico o de suspenso para la fase de Preguntas.
- `bgm_victory.mp3`: Tema épico y triunfal para la fase de Resultados/Podio final.

> [!IMPORTANTE]
> Asegúrate de que los archivos sean verdaderamente MP3. Renombrar un `.wav` a `.mp3` no cambiará la codificación y puede causar fallos en algunos dispositivos móviles. Utiliza un conversor si tu IA te arroja formato WAV u OGG.
